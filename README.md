# 🚗 Auto Partes Premium

Plataforma web moderna para la gestión y visualización de inventario de autopartes, integrada dinámicamente con **Google Sheets** como backend, con buscador avanzado, filtros profesionales, paginación, chat interactivo y contacto directo por WhatsApp.

Diseñada para escalar con cientos o miles de productos sin perder rendimiento.

---

## ✨ Características principales

- 📊 Inventario dinámico desde Google Sheets (CSV público)
- 🔎 Buscador por **Año → Marca → Modelo**
- 🎯 Filtros laterales profesionales (Categoría, Año, Marca, Modelo)
- 📄 Paginación automática para grandes inventarios
- 💬 Chatbox interactivo con detalle de producto
- 📲 Contacto directo por WhatsApp por producto
- 🖼️ Soporte de imágenes por inventario
- ⚡ Carga rápida y responsive (TailwindCSS)
- 🔄 Auto-refresco de datos cada 60 segundos
- 📱 Diseño mobile-first

---

## 🧱 Tecnologías utilizadas

- **HTML5**
- **TailwindCSS**
- **JavaScript Vanilla**
- **Google Sheets (CSV público)**
- **WhatsApp API**
- **Instagram Link**
